Corpus framing of this source: Agentic coding expands implementation capacity while retaining returns to domain expertise

Corpus synthesis of this source: Agentic Coding and Persistent Returns to Expertise analyses Claude Code usage from October 2025 to April 2026. It reports broader, higher-value tasks and associates task-specific expertise with greater agent activity and better outcomes. It presents these findings as early signals of possible labour-market change, not established economy-wide effects.

Corpus source-specific finding

The report studies a large but bounded sample of interactive Claude Code use.

Exact returned source excerpt

This report provides evidence on how Claude Code is used in practice, based on a [privacy-preserving analysis](https://www.anthropic.com/research/clio) of ~400,000 interactive sessions from ~235,000 people between October 2025 and April 2026.

Exact returned source excerpt

- All classifiers in this report use Claude Sonnet 4.6 unless otherwise noted.

Corpus source-specific finding

Users generally retain planning authority while Claude handles execution.

Exact returned source excerpt

In the typical session, the user makes about 70% of planning decisions while Claude makes about 80% of execution decisions.

Exact returned source excerpt

In our historical data from October to April, each prompt the user sends sets off a chain of around 10 actions taken by Claude on average––and sometimes over 100.6 In each turn, Claude reads files, edits code, runs commands, and writes on average 2,400 words of output.

Corpus source-specific finding

Task-specific expertise correlates with more agent activity, independently of several observed session characteristics.

Exact returned source excerpt

### Level of expertise From each transcript, Claude rates the user's apparent expertise at the task on a five-point scale from novice to expert.

Exact returned source excerpt

The expertise classifier looks for three signals: how precisely the user frames their directions, what they ask Claude to verify, and whether the user tends to correct Claude or Claude tends to correct the user.

Corpus source-specific finding

The authors report better outcomes for domain experts, but a modest advantage over intermediate users.

Exact returned source excerpt

We also see evidence that domain expertise, and not coding proficiency, amplifies effective use of the tool.

Exact returned source excerpt

In particular, domain experts succeed more often, and more easily recover from errors and misunderstandings.

Corpus source-specific finding

Legal occupations rank among the fastest-growing non-software user groups, but occupation is inferred rather than directly observed.

Exact returned source excerpt

We were able to infer occupation in about 70% of sessions.

Exact returned source excerpt

Within this set, Computer and Mathematical Occupations, a category which encompasses most software-related jobs, is unsurprisingly the largest group.

Corpus source-specific finding

Usage shifts away from debugging toward operating software, writing and data analysis.

Exact returned source excerpt

The clearest change is that the share of sessions spent fixing broken code fell from 33% to 19% (Figure 4).

Exact returned source excerpt

Operating software grew from 14% to 21% of sessions.

Corpus source-specific finding

Estimated task value rises, but the measure is a relative freelance-market proxy.

Exact returned source excerpt

We approximate each session's economic value by asking what the work would cost on a freelance marketplace, calibrated against a public dataset of real postings.

Exact returned source excerpt

By this measure, the estimated value of the average session rose by 27% between October and April.

Corpus source-specific finding

The labour-market implication is conditional: agents may absorb implementation work while rewarding problem understanding.

Exact returned source excerpt

Coding agents are not substituting for domain expertise—the more understanding a worker brings to an agent, the more quality work the agent is able to do.

Exact returned source excerpt

If these patterns hold across the economy, it suggests that while agentic coding tools may be absorbing some implementation-heavy work, they are also rewarding those with firm understanding of the problems they solve on the job.

Corpus framing of this source: Agentic Coding and Persistent Returns to Expertise

Corpus synthesis of this source: The source analyses interactive Claude Code sessions to argue that coding agents reduce the importance of a programming background but preserve strong returns to domain expertise. It links expertise to higher success and more productive human-agent collaboration, describes the occupations and work represented in the sessions, and qualifies the findings because outcomes and classifications are proxy measures rather than validated real-world impacts.

Corpus source-specific finding

Domain expertise predicts success more strongly than coding background

Exact returned source excerpt

It appears that coding agents are making a coding background less relevant to successful programming.

Exact returned source excerpt

At the same time, successful sessions are more likely to exhibit domain expertise.

Corpus source-specific finding

Experts obtain more work from the agent and handle difficulties more effectively

Exact returned source excerpt

Sessions rated expert reach verified success more than twice as often as those rated novice, and when a session hits trouble, novices abandon the session at several times the rate of everyone else.

Exact returned source excerpt

The shape of the collaboration gives this picture more color—domain experts are able to direct Claude to do more work with each instruction they give.

Corpus source-specific finding

Coding agents may broaden who can perform technical work, but they do not eliminate expertise barriers

Exact returned source excerpt

A person with such command, in any field, may now be able to do technical work they previously could not.

Exact returned source excerpt

A person without any such expertise will get far less from the same tool.

Corpus source-specific finding

The analysis partially controls for task selection and other confounding differences

Exact returned source excerpt

One might worry that expertise isn't the real driver—perhaps experts simply pick different tasks, or differ in other ways.

Exact returned source excerpt

Throughout this section, we partially address this worry by comparing sessions doing the same kind of work, at the same estimated value, in the same month, on the same subject, from people in the same broad occupation group, and ask how outcomes differ by the person’s rated expertise.

Corpus source-specific finding

Claude Code use extends beyond software occupations

Exact returned source excerpt

## **Who uses Claude Code, and for what** ### **The users** To understand who is doing this work, we infer each user's occupation from the session transcript, mapping it to one of 23 major groups in the Bureau of Labor Statistics’ Standard Occupational Classification (SOC) taxonomy.

Exact returned source excerpt

The classifier is instructed to rely only on signals such as the project context the agent loads at the start of a session, the names and structure of their files, any artifacts they reference (e.g., legal filings, clinical data, financial reports, a curriculum, etc.) and vocabulary they use.7 It is explicitly instructed not* to treat the act of coding as evidence of a coding profession.

Corpus source-specific finding

Interactive sessions cover coding, software operation, planning, analysis and communication

Exact returned source excerpt

5 Four modes involve writing or maintaining code directly: building* something new, *fixing* something broken, *testing* code, and *orchestrating* other agents or automated pipelines.

Exact returned source excerpt

Another category is *operating* software—deploying, configuring, running pipelines, monitoring systems.

Corpus source-specific finding

Classifier checks offer supporting validation, but the findings remain preliminary and do not establish economic impact

Exact returned source excerpt

We classify each session by having a model read its transcript, then using our privacy-preserving analysis tool, we check them against telemetry that's recorded automatically for every session, including whether any lines of code were added or deleted.

Exact returned source excerpt

The two sources have high agreement—for instance, more than 90% of sessions our classifier labeled as creating or modifying code showed code changes in the telemetry.
