Corpus framing of this source: Training a State-of-the-Art Legal Agent with Harvey

Corpus synthesis of this source: Harvey reports that training GLM-5.1 on a document-intensive acquisition-memo task improved legal-agent performance through more targeted tool use, reliable artifact production, greater numerical and factual specificity, and stronger grounding in supplied sources. It supports the account with trace examples and rubric changes across a 180-item evaluation set, while noting that the baseline already scored about 85% and that hallucination declined without an explicit hallucination penalty.

Corpus source-specific finding

Harvey evaluates the model on producing a source-grounded acquisition memo and frames improvement against an already strong baseline.

Exact returned source excerpt

In this task, the assignment is to review a set of documents for a proposed acquisition for Prism and produce a memo describing transaction structure, risk areas, and recommended next steps backed by specific details from the source documents.

Exact returned source excerpt

Since the model baseline score starts around 85%, only approximately 1,500 rubric criteria remain to be improved across the 180-item test set (with roughly 10,000 total criteria).

Corpus source-specific finding

Training made document retrieval more targeted and efficient as evaluation scores improved.

Exact returned source excerpt

Over the course of training, we see total tool usage fall; this breaks down mostly into fewer read calls with a consistent number of other tool calls, like bash and grep.

Exact returned source excerpt

As the eval score continues to improve, this reflects the model learning to more effectively use its tools and not just bulk-read all the files in the source documents.

Corpus source-specific finding

Training improved artifact completeness by teaching the model to use the available document-generation and verification workflow.

Exact returned source excerpt

- Builds a custom docx Python script that ultimately fails to construct an artifact due to a parsing error — instead of using the available docx generation tool.

Exact returned source excerpt

- Failure to check the correct location (/workspace/outputs) for the output artifact, resulting in 'No such file or directory' and lack of verification of the docx file type.

Corpus source-specific finding

Specificity and exactness produced the largest reported rubric gain among the three identified behaviors.

Exact returned source excerpt

- **Specificity and Exactness**: The base GLM-5.1 model suffers from poor calculations or referring to imprecise numbers, often rounding figures during math (like 1.9 to 2), which is punished by legal graders.

Exact returned source excerpt

This behavior flips 243 criteria from failing to passing.

Corpus source-specific finding

Training reduced ungrounded claims and hallucinated source material even without an explicit hallucination penalty.

Exact returned source excerpt

- **Grounding**: Without training, the checkpoint sometimes hallucinates source document items or invents findings from outside the provided documents.

Exact returned source excerpt

- Poorly supported claims like "Vertical concerns arise from ClearScript PBM, LLC, Meridian's wholly-owned pharmacy benefits management subsidiary..." lack evidence.
