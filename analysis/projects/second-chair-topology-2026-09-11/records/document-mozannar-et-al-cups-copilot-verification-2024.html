Corpus framing of this source: CUPS study: measuring the human work surrounding AI code suggestions

Corpus synthesis of this source: Reading Between the Lines: Modeling User Behavior and Costs in AI-Assisted Programming examines how programmers interact with GitHub Copilot, rather than testing productivity against unaided coding. Its participant-labeled telemetry reveals substantial interaction time, verification after acceptance, and prompt-crafting friction, alongside users’ reported benefits to coding flow. The authors recommend metrics that capture checking and subsequent code retention.

Corpus framing of this source: CUPS study: measuring hidden work in AI-assisted programming

Corpus synthesis of this source: The study contributes the CodeRec User Programming States (CUPS) framework, which labels telemetry intervals by meaningful programmer activity to expose interaction costs that acceptance and task-level metrics miss. In a 21-participant Copilot study, it finds that verification consumes substantial time, prompt crafting has distinctive interaction patterns, and users report both productivity benefits and quality concerns. It proposes revised metrics, counterfactual studies and predictive state models, while limiting its conclusions to short, largely Python-based experimental tasks.

Corpus source-specific finding

The authors argue that conventional metrics obscure important work created by AI code completion.

Exact returned source excerpt

Existing interaction metrics, such as suggestion acceptance rates, time to accept (i.e., the time a suggestion remains onscreen), and reduction of tokens typed, tell only part of this interaction story.

Exact returned source excerpt

In both scenarios, considerable work verifying and editing suggestions occurs after the programmer has accepted the recommended code.
