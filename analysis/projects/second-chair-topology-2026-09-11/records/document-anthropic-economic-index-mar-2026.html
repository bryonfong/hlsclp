Open topic: Junior hiring: Stable unemployment can hide adjustment

Corpus framing of this source: Claude usage: learning effects, broader task mixes and API automation exposure

Corpus synthesis of this source: Anthropic’s March 2026 Economic Index reports that experienced users collaborate more successfully with Claude, while task mixes diverge between Claude.ai and the API. It treats learning-by-doing and faster job transformation as plausible interpretations, not established causal effects, and cautions that Claude usage does not represent the wider US economy.

Corpus framing of this source: Anthropic Economic Index Report: Learning Curves (March 2026)

Corpus synthesis of this source: Anthropic analyses one million sampled conversations from Claude.ai and its first-party API to describe changes in task mix, collaboration patterns, model selection and outcomes by user tenure. It finds broader consumer use, a migration of coding activity toward the API, modestly more augmentation, and higher success among experienced users. It treats learning-by-doing as a plausible but not yet causal explanation and warns that unequal gains could reinforce labour-market inequality.
